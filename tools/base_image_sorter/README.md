# 拠点画像 仕分けツール（base_image_sorter）

LoRA学習用の拠点サムネイル画像を、**拠点名 × 時間帯**で仕分けする補助デスクトップアプリ。
画像を目視して **拠点（曜日別リスト）** と **時間帯（朝/昼/夕/夜）** を選び、命名ルールで
リネームして `material/back/<拠点名>/` へ移動する。サムネ生成・AI自動分類はしない。

`tools/effect_sorter` と同じ構成・スタイル（CustomTkinter + pink_theme + HachiMaruPop）。
effect_sorter にあった **キャラクター名の分類 / front・back 判定 / Ollama翻訳 / 履歴** は持たない。

## 起動

リポジトリのルートから:

```
python tools/base_image_sorter/base_image_sorter_app.py
```

Windows ではルートの `拠点仕分け起動.bat` をダブルクリックしてもよい。

## 基本フロー

1. 仕分けたい画像を右の **「入力画像」エリアへドラッグ&ドロップ**（または **「＋ 画像を追加」**）。
   フォルダごとドロップすると中の画像をまとめて取り込む。
2. 1枚クリックするとプレビューに大きく表示（投入直後は自動で1枚目を選択）。
3. **拠点名**（左の曜日別リストから選択）と **時間帯**（朝/昼/夕/夜ボタン）を選ぶ。
4. **✔ 確定** で自動リネーム → `material/back/<拠点名>/` へ移動（＝元画像はそこへ移動完了）。
5. 同じ位置にスライドしてくる次の画像が自動選択され、続けて仕分けできる。

**保存先は `material/back` に固定**（拠点ごとにサブフォルダ）。入力フォルダ・出力フォルダの
選択画面は無い（D&D／追加で受け取り、固定先へ移動する方式）。

## キーボードショートカット

| キー | 動作 |
|---|---|
| Enter | 確定 |
| 1 / 2 / 3 / 4 | 時間帯を 朝 / 昼 / 夕 / 夜 に切替 |
| → | スキップ（次の画像へ） |

## D&D

エクスプローラから「入力画像」エリア（またはウィンドウ）へ**画像／フォルダ**をドラッグ&ドロップ
すると仕分け対象に追加します。`tkinterdnd2` が必要です。

```
pip install -r tools/base_image_sorter/requirements.txt
```

`tkinterdnd2` が無い環境でもアプリは起動します。その場合は **「＋ 画像を追加」** を使ってください。

## 命名ルール

```
{拠点名英語}_{時間帯}_{3桁連番}.png
例: Forest_of_Seclusion_day_001.png
    Ehwaz_Hill_night_003.png
```

- 区切りはアンダースコア1個 `_`。拠点名のスペルはそのまま（スペースは元から `_`、
  `Anti-troll_Fortification` のハイフンもそのまま）。**ファイル名は英語のみ**。
- 時間帯は `day` / `morning` / `evening` / `night` の4種。
- 連番は3桁ゼロ詰め。**保存先（`material/back/<拠点名>/`）の既存ファイルを見て自動採番**し、
  既存があっても上書きしない。連番は「拠点 × 時間帯」ごとに続き番号になる。
- 入力が png ならバイト無劣化でコピー、jpg/jpeg/webp なら PNG に変換して保存。

拠点リストのボタンは表示の助けとして **「英語名（日本語名）」** の2行で出すが、日本語名は
表示専用で、ファイル名には使わない。日本語名が実際と違う場合は `bases.py` の `BASE_JP` を
書き換えれば直る（ファイル名には影響しない）。

## 出力先の構造（拠点ごとにサブフォルダ）

```
material/back/
├── Forest_of_Seclusion/
│   ├── Forest_of_Seclusion_day_001.png
│   └── Forest_of_Seclusion_night_001.png
├── Ehwaz_Hill/
│   └── Ehwaz_Hill_day_001.png
├── _hold/    （保留した画像）
└── _trash/   （削除＝退避した画像）
```

## 連続仕分け（スキップ / 保留 / 削除）

確定・保留・削除のいずれかで1枚処理すると、**その位置にスライドしてくる次の画像が
自動選択**される。プレビュー下に **「残り N 枚」** を表示。

| ボタン | 動作 | 元画像 |
|---|---|---|
| ⏭ スキップ | 何もせず次の画像へ（非破壊） | そのまま残る |
| 保留 | 後で処理する画像を `material/back/_hold/` へ退避 | copy→検証後に移動。復元可 |
| 🗑 削除 | 確認のうえ `material/back/_trash/` へ退避（**完全削除はしない**） | copy→検証後に移動。復元可 |
| クリア | 一覧を空にするだけ（ファイルは移動も削除もしない） | そのまま残る |

保留・削除は確定フローと同じく **copy→検証→元削除** で行い、検証に失敗した場合は
元画像をそのまま残す。`_hold` / `_trash` 内で同名が衝突したときは `_dup1` 等の
サフィックスを付けて退避し、既存を上書きしない。

## ファイル

| ファイル | 役割 |
|---|---|
| `base_image_sorter_app.py` | エントリーポイント（GUI） |
| `bases.py` | 拠点名リスト（曜日別）・日本語表示名・時間帯の定義データ |
| `paths.py` | ルート検出・固定保存先（material/back）のパス解決 |
| `naming.py` | ファイル名生成・バリデーション・連番取得 |
| `widgets.py` | 再利用UI部品（プレビュー・拡大・サムネ一覧） |
