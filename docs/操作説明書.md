## 1. このアプリでできること

- 日付・拠点名・ギルド名（最大5）・キャラ画像を入力すると、**背景＋エフェクト＋文字を重ねた1枚のサムネPNG**を生成します。
- 背景は **手動指定／フォルダからランダム選択／AI生成** のいずれでもOK。
- キャラの後ろに置く**後方エフェクト（炎・氷・雷など）**も手動指定またはAI生成できます。
- 文字・キャラ・エフェクトは**プレビュー上でドラッグ／矢印キーで移動・拡縮**できます。
- レイアウト（位置・サイズ・フォント）は**テンプレート**として保存・切替できます。
- ギルド名は**言語を自動判定**して、日本語/韓国語/中国語/英語/ロシア語ごとのフォントを使い分けます。

## 2. 起動方法

| やりたいこと | 操作 |
|---|---|
| サムネ作成アプリを直接開く | `python main.py`（Windows は `起動.bat` をダブルクリック） |
| 3つのツールから選んで開く | `python launcher.py`（Windows は `ランチャー起動.bat`） |

ランチャーからは次の3つを開けます。

- 🖼️ **サムネ作成** … 本体アプリ
- 🎨 **モデル / LoRA 比較** … 複数モデル×LoRAで一括生成して見比べる
- 🗂️ **素材仕分け** … エフェクト素材を目視で仕分け・リネーム・移動

## 3. 画面の見方

本体アプリは**左右2分割**です。

- **左：Settings（設定入力欄）** … 日付・曜日・拠点・ファイル名・ギルド・キャラ・AI生成・Options・テンプレート・Export
- **右：プレビュー** … 合成結果のリアルタイム表示。直下に `👁️ Preview` / `🎲 New BG` ボタン、選択中の要素名、操作ヒントが並びます。

---

## 4. 基本の作り方（5ステップ）

1. **📅 Date / Day** … 日付を入力（例 `2026.06.04`）、曜日を選ぶ。曜日を変えると、その曜日の拠点候補が🏰Nodeのプルダウンに反映されます。
2. **🏰 Node** … 拠点をプルダウンから選ぶ、または直接入力。
   - 日付と拠点から **💾 Output Filename**（出力ファイル名）が自動で `日付_拠点名` の形で作られます。
3. **⚔️ Guild Names** … ギルド名を最大5つ入力（各行に個別フォント指定欄あり、任意）。
4. **🧙 Character** … `Pick Character` を押し、`material/character/` の中からキャラ画像を選ぶ。
5. **👁️ Preview** で確認 → **📤 Export PNG** で `outputs/` に保存。
   - 同名ファイルがある場合は `_01`, `_02` … と自動で連番が付きます。

> 背景を何も指定しないと、`assets/backgrounds/` からランダムに1枚選ばれます。
> プレビュー中は同じ背景が固定され、別の背景にしたいときは **🎲 New BG** を押します。

---

## 5. プレビュー上での直接編集

プレビュー内の**文字・キャラ・後方エフェクト**をクリックして選択し、位置やサイズを直接調整できます。

| 操作 | 動き |
|---|---|
| クリック | その要素を選択（選択中の名前が右パネルに表示） |
| ドラッグ | 移動 |
| 矢印キー | 1px ずつ移動 |
| Shift + 矢印キー | 10px ずつ移動 |
| Ctrl + ↑ / ↓ | サイズ（文字サイズ／画像の拡大率）を増減 |

調整結果は Options 内の数値欄にもそのまま反映されます。

## 6. AI画像生成（背景・エフェクト）

左の「🤖 AI Generate」セクションで使います。**ローカルのComfyUIを使うため無料・APIキー不要**です。

### 使い方
1. **Node（拠点名）** を入力（背景プロンプトは拠点名から自動で組み立てられます）。
2. **Effect type** でエフェクト種類を選ぶ（`fire / ice / lightning / dark / holy / flower / butterfly / blue_purple_magic` など。`config/ai_prompts.json` に追加すると選択肢も増えます）。
3. ボタンを押す。
   - **✨ Generate BG + Effect (AI)** … 背景とエフェクトを同時生成
   - **BG only** … 背景だけ
   - **Effect only** … エフェクトだけ
4. 生成中はピンクの進行表示が出ます。完了すると自動でフォームにセットされ、プレビューに反映されます。
5. 結果は次のフォルダに保存され、後から `Select Background` / `Select Effect` で選び直せます。
   - 背景: `assets/backgrounds/ai/`
   - エフェクト: `assets/effects/ai/`

### 仕組みのポイント
- アプリ起動時にComfyUIへ自動接続し、未起動なら設定に従って裏で自動起動を試みます。
- `material/サンプル/<種類名>/` に見本画像を置くと、その雰囲気に寄せて生成します（img2img）。
- 透過に未対応のプロバイダーでは、黒背景で生成 → 明るい部分を不透明にして透過PNG化します（発光エフェクト向け）。

> **初回セットアップ（ComfyUIの導入・モデル配置・起動パス設定）は必ず別冊を参照してください。**
> → [AI画像生成_やり方説明書.md](AI画像生成_やり方説明書.md)

## 7. Options（詳細設定）

「⚙️ Options」ボタンで開閉します。プレビューで微調整した値はここにも反映されます。

| 区分 | 項目 | 説明 |
|---|---|---|
| 🖼️ Manual Background | 背景パス / Select Background | 手動で背景を指定（空ならランダム or AI） |
| 🌟 Manual Back Effect | エフェクトパス / Select Effect | 手動でエフェクトを指定（AI生成すると自動セット） |
| 🌐 Guild Font by Language | ja / ko / zh / en / ru | 言語ごとのギルド用フォント（字体サンプル付き） |
| 🔤 Common Font / Branding | 共通フォント・ブランディング文・専用フォント | 日付・拠点名・Node War と右下表示の設定 |
| 📐 Character | X / Y / Scale | キャラの位置・拡大率 |
| 🌟 Back Effect | X / Y / Scale | エフェクトの位置・拡大率 |
| 📝 Text | Date / Node / Node War / Guild / Branding の X・Y・Size | 各テキストの位置・サイズ・行間 |

## 8. テンプレート

レイアウト一式（各要素の位置・サイズ・フォント・ブランディング）を JSON として保存・呼び出しできます。

- **📋 Template** … プルダウンで `templates/` 内のテンプレートを切替。
- **💾 Save as Template** … 現在の設定を、選択中のテンプレート名で上書き保存。
- 標準テンプレートは `templates/node_war_default.json`。

テンプレートに含まれる主な情報（`node_war_default.json` より）:
- `canvas` … 1920×1080
- `text` … date / node_name / subtitle(Node War) / guilds の位置・色・縁取り・発光（glow）
- `character` / `back_effect` … 位置・拡大率・不透明度
- `branding` … 右下表示テキスト
- `background.overlay_opacity` … 暗色オーバーレイの濃さ（標準 0.3）
- `language_fonts` / `font_path` / `guild_font_paths` … フォント設定

---

## 9. フォントと多言語

- **共通フォント**（`font_path`）… 日付・拠点名・Node War・（指定なければ）ブランディングに使用。
- **ギルド名のフォント**は次の優先順で決まります。
  1. ギルド行に**個別指定したフォント**
  2. **言語別フォント**（ギルド名から言語を自動判定 → ja/ko/zh/en/ru のフォントを使用）
- 言語別フォントは Options で選べ、選択中フォントの字体サンプルが隣に表示されます。
- フォント素材は `font/JP` `font/KR` `font/CN` `font/EN` `font/RU` を参照します（対応拡張子: `.ttf` `.otf` `.ttc`）。

## 10. サブツール（ランチャー）

### 🎨 モデル / LoRA 比較（`tools/model_tester/`）
同じプロンプト・シードを「複数モデル × 複数LoRA」で一括生成し、行=モデル / 列=LoRA のグリッドで見比べます。
ComfyUIを使用（本体の `ai_config.json` を流用）。結果は `outputs/model_tester/<日時>/` に保存。
詳細 → [tools/model_tester/README.md](../tools/model_tester/README.md)

### 🗂️ 素材仕分け（`tools/effect_sorter/`）
エフェクト素材を目視で **クラス / 位置 / effect① / effect②** に分類し、命名ルールでリネームして
`material/effect/<クラス>/<位置>/<effect①>/` へ移動します。スキップ／保留／削除での連続仕分けに対応。
日本語→英語変換にローカルの Ollama を利用可。
詳細 → [tools/effect_sorter/README.md](../tools/effect_sorter/README.md)

## 11. コマンドラインからの生成（cli.py）

GUIなしでサムネを生成できます（動作確認・バッチ処理向け）。

```
python cli.py \
  --bg assets/backgrounds/dark_castle/bg01.jpg \
  --char material/character/chara01.png \
  --effect assets/effects/ai/effect01.png \
  --date "2026.06.04" \
  --node "リンチファーム遺跡" \
  --guilds "GuildA" "GuildB" "GuildC" \
  --font font/JP/NotoSansJP-VariableFont_wght.ttf \
  --font-ja font/JP/KiwiMaru-Medium.ttf \
  --template node_war_default \
  --out outputs/test_output.png
```

主なオプション: `--bg` `--char` `--effect` `--date` `--node` `--guilds`（最大5）
`--font` `--branding` `--branding-font` `--guild-fonts` `--font-ja/-ko/-zh/-en/-ru` `--template` `--out`。
`--bg` を省くと `assets/backgrounds/` からランダム選択されます。

AI生成の動作確認コマンド（課金なし）:
```
python -m core.ai_image check               # セットアップ確認
python -m core.ai_image bg "Ehwaz Hill"     # 背景を1枚生成
python -m core.ai_image effect fire          # エフェクトを1枚生成
```

## 12. 設定ファイル早見表

| ファイル | 役割 | 触ってOK? |
|---|---|---|
| `config/ai_config.json` | AIプロバイダー・接続先・画質/速度・自動起動パス | ✅ |
| `config/ai_prompts.json` | 背景・エフェクトのプロンプト文・拠点ごとのヒント | ✅ |
| `data/node_options.json` | 曜日ごとの拠点候補（プルダウン） | ✅ |
| `templates/*.json` | レイアウトテンプレート | ✅（アプリから保存推奨） |
| `config/pink_theme.json` | 画面のピンク配色テーマ | △ |
| `core/*.py` | 合成・テキスト描画・AI生成の本体 | ❌ 触らない |

`ai_config.json` の主な調整項目（`comfyui` セクション）:

| 設定 | 意味 | 目安 |
|---|---|---|
| `ckpt_name` | 使うモデル名 | 空=自動 / 指定はファイル名 |
| `width` / `height` | 生成サイズ | SD1.5系 768×432 / SDXL系 1344×768 |
| `steps` | 描き込み回数 | 20=速い〜35=丁寧 |
| `auto_start` | アプリ起動時にComfyUI自動起動 | `true` |
| `python_path` / `main_path` / `working_dir` | 自動起動するComfyUIの場所 | 自分のPCに合わせる |
| `denoising_strength` | 見本への寄せ具合 | 0.6=近い〜0.8=変化大 |
| `timeout_seconds` | 生成待ちの上限秒 | 遅いなら600へ |

> JSONは `"` や `,` を消すと壊れます。**値の中身だけ**書き換えてください。

## 13. フォルダ構成

```
bdm-thumbnail_app_v02/
├─ main.py / launcher.py / cli.py     # 起動スクリプト
├─ core/        # 合成エンジン: composer / text_renderer / template / ai_image
├─ ui/          # GUI: app（メイン画面）/ preview（プレビュー）
├─ tools/       # サブツール: model_tester / effect_sorter
├─ config/      # ai_config.json / ai_prompts.json / pink_theme.json
├─ templates/   # レイアウトテンプレート
├─ data/        # node_options.json（曜日別拠点候補）

├─ assets/      # backgrounds（背景・AI出力先）/ effects（エフェクト・AI出力先）
├─ outputs/     # 生成したサムネPNGの保存先
└─ docs/        # 説明書

## 14. よくあるトラブル

| 症状 | 原因 | 対処 |
|---|---|---|
| AI生成で「ComfyUIに接続できません」 | ComfyUI未起動／自動起動パスが違う | 手動起動するか `ai_config.json` の `python_path`/`main_path`/`working_dir` を確認 |
| 「モデル(checkpoint)が見つかりません」 | モデル未配置 | ComfyUIの `models/checkpoints/` に `.safetensors` を置く |
| AI生成がタイムアウト | 生成が遅い | `ai_config.json` の `timeout_seconds` を 600 などに増やす |
| キャラを選んでも出ない | パスが解決できない | `material/character/` 内の画像を `Pick Character` から選ぶ |
| ギルド名が豆腐（□）になる | その言語のフォントが無い/未対応 | Options の言語別フォント、または行の個別フォントを設定 |
| 背景が毎回変わる | 背景未指定でランダム選択中 | Options で背景を手動指定する（固定したいとき） |
| プレビューは出るのに保存されない | Export 前にプレビューに失敗 | エラーダイアログの内容を確認し、入力値・フォント・画像パスを見直す |

困ったらまず AI セットアップ確認コマンドが有効です:
```
python -m core.ai_image check
```
